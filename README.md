# Antes do Clique — Golpe ou Seguro?

Landing page educativa e interativa desenvolvida para o projeto **Antes do Clique**, com o objetivo de conscientizar o público sobre golpes cibernéticos e incentivar atitudes mais seguras no ambiente digital.

O projeto foi criado como atividade acadêmica do curso de **Sistemas de Informação**, servindo como material informativo e ilustrativo para uma minipalestra presencial sobre o tema *Golpes Cibernéticos: Como Identificar, Desconfiar e se Proteger*.

## Tecnologias utilizadas

- HTML5 semântico
- CSS3
- JavaScript
- CSS Grid e Flexbox
- Variáveis CSS
- Media Queries
- Design responsivo
- Práticas de acessibilidade

## Funcionalidades

- Dinâmica interativa **"Golpe ou Seguro?"**, com três situações fictícias do cotidiano
- Identificação de duas tentativas de golpe e uma atitude segura
- Feedback explicativo após cada resposta
- Pontuação final e possibilidade de refazer a atividade
- Apresentação visual dos resultados de uma pesquisa com 30 pessoas acima de 40 anos
- Orientações práticas para identificar e prevenir golpes digitais
- Navegação entre seções e botão para retornar ao topo
- Interface responsiva para computadores, tablets e celulares

## Objetivo

Aplicar conhecimentos de desenvolvimento front-end na criação de uma ferramenta educativa, acessível e interativa, capaz de facilitar a compreensão dos riscos presentes no ambiente digital.

Além de trabalhar conceitos de HTML, CSS e JavaScript, o projeto busca transformar informações sobre segurança digital em uma experiência simples e participativa.

## Sobre o projeto

O **Antes do Clique** foi desenvolvido a partir de uma pesquisa realizada com 30 participantes de 40 anos ou mais, que investigou hábitos digitais, experiências com golpes e conhecimentos sobre fraudes virtuais.

Os resultados orientaram a construção de três seções principais:

1. **Golpe ou Seguro?** — dinâmica interativa para estimular a identificação de situações suspeitas.
2. **O que a pesquisa revelou** — apresentação dos dados coletados e dos principais desafios enfrentados pelos participantes.
3. **Como se proteger** — orientações práticas para reconhecer golpes, confirmar informações e proteger dados pessoais.

O projeto utiliza situações fictícias inspiradas em modalidades comuns de fraude, como o falso funcionário de banco e o falso parente solicitando Pix.

## Aviso

Este projeto possui finalidade exclusivamente acadêmica e educativa.

As situações apresentadas na dinâmica são fictícias e foram desenvolvidas para estimular a conscientização sobre segurança digital. O conteúdo não substitui orientações específicas de instituições financeiras ou autoridades competentes.
